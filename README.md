# Lab: Operadores Lógicos y Tablas de Verdad

## 📖 Descripción del Laboratorio

Ejercicios prácticos para dominar la lógica booleana, tablas de verdad, operadores `AND` (`&&`), `OR` (`||`) y `NOT` (`!`) en JavaScript.

---

## 🎯 Objetivos y Requisitos Técnicos

- [x] Evaluación lógica con `&&` y `||`
- [x] Negación lógica con `!`
- [x] Reglas de precedencia de operadores
- [x] Simplificación de condiciones lógicas complejas

---

## 🛠️ Tecnologías y Herramientas

- **JavaScript ES6+**
- **Manipulación del DOM**
- **HTML5 & CSS3**
- **Git & GitHub**
